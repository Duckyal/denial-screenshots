## 拼图与拆图

### 多图多形状拼图（工作台）
- **一期已完成**（2026-11-03，feature/collage-split）：「更多功能」面板 →
  `PathChooserPanel` 多选（跨目录、按勾选顺序）→ `editor/collage.dart`
  等比网格合成 → 新画布。
- **工作台化已完成主体**（2026-11-04，40be7bf + 后续未提交批次）：框架=
  开在图片上的窗口（cover 取景，永不露白）；双击框架=画布聚焦到该框架
  （长边≈屏幕短边 92%、居中）；预览态框内拖=平移取景、滚轮=缩放取景；
  全景态拖框任意位置=移框、手柄=调框；连续加图走追加不重建；选中+Del
  统一删除；保存/复制/置顶按框架包围盒出图（透明底）+ 面板旁只读预览卡；
  进出与每步调整全支持撤销/重做（快照含槽 rect/frame 状态）。
- **待完善（2026-11-05 用户验收记录，按优先级）**：
  1. **工作台不需要"框外拖动/视角平移"**——双击聚焦缩放已经够用；
     当前实现里的空白拖平移视角、框外滚轮平移视角属于多余功能，应移除
     （或至少不再作为交互卖点）。
  2. **框内图片在框内的缩放和平移仍有问题**——预览态拖拽平移、滚轮
     取景缩放的行为还没调到用户满意的程度（1× 无平移余量、锚点手感、
     与移框手势的边界都要重新审视）。
  3. **框架之间需要自动对齐**——之前做过的"平铺式吸附"被否（效果差：
     线太密、吸得突兀），需要更好的方案（如仅对齐相邻框的边、拖近才
     显示参考线、松手才吸附）。
- 一期遗留候选：留白背景色可选。

## 已尝试后回退的（stash 里有完整实现）

- **横向长截图**（`stash@{1}`）：影子双拼器定轴 + 转置复用匹配核。合成数据验证通过，
  真机翻车：每帧双管线 + 观察期整图重定位导致卡顿，预览小窗矮宽条不可读。
  重启的正确姿势：前几帧用探针位移方向**先探测再单跑**，不做双跑。

  连带底图字节。功能本身可用，交互没打动用户。若重做，砍成"长截图会话内删段"
  单一场景，不做通用裁剪工具。
