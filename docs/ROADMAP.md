## 拼图与拆图

### 多图多形状拼图（工作台）
- **一期已完成**（2026-11-03，feature/collage-split）：「更多功能」面板 →
  `PathChooserPanel` 多选（跨目录、按勾选顺序）→ `editor/collage.dart`
  等比网格合成 → 新画布。
- **工作台化已完成主体**（2026-11-04，40be7bf + 后续未提交批次）：框架=
  开在图片上的窗口（cover 取景，永不露白）；双击框架=画布聚焦到该框架
  （长边≈屏幕短边 92%、居中）；预览态框内拖=平移取景、滚轮=缩放取景；
  全景态拖框任意位置=移框、手柄=调框；连续加图走追加不重建；选中+Del
  统一删除；保存/复制/置顶按框架包围盒出图（透明底）+ 面板旁只读预览卡；
  进出与每步调整全支持撤销/重做（快照含槽 rect/frame 状态）。
- **①三项已重写并验收通过（2026-11-06，dev add3735）**：
  1. 框外拖动/视角平移**已移除**：空白处拖动只取消选中，框外滚轮不响应；
     看全局唯一路径 = 双击聚焦（`_panCanvas` 的工作台自由平移补丁一并
     删除，恢复普通语义）。
  2. 框内图片缩放平移**换模型重做**：cover 取景（1× 时取景=整图、没有
     平移余量，就是"拖不动"的根源）改为**自由放置**——以"适配框架
     (contain)"为 1× 基准，zoom 0.2×–8×：可以小于框架（四周留白，
     构图用），也可以大于框架（框架=窗口，只露框住的部分）；平移无边界
     限制；滚轮以指针为锚（指针下内容钉住）；手柄调框时图片在世界里
     钉住不动，只有窗口变形。撤销快照改记 (rect, imageRect)。
  3. 框架自动对齐**重做**：只对齐**其他框架**的边/中线（不再拿画布边/
     中线当靶子，那是"线太密"的来源）；拖近（屏幕 12px 容差）**实时
     显示蓝色参考线**但框完全跟手，**松手才吸附**——消除"吸得突兀"。
     注：吸附落位曾有顺序 bug（先清 move slot 再读 → 吸附从未生效），
     已修；手柄调框同样参与吸附。
- 验收轮追加修复（2026-11-05 深夜，同一 dev 提交线）：
  - **Alt+A 编辑器内重截**：合成器全局快捷键优先于 surface 键盘捕获，
    编辑器里按 Alt+A 到不了编辑器按键层。改由框选 surface 检测编辑器
    可见 → 转发 retrigger 信号 → 编辑器关闭自己并延时拉起新选区（未
    交付内容仍先走「放弃编辑？」确认，选"继续编辑"取消连锁）。
  - **编辑器消息条**：编辑器树无 Scaffold，ScaffoldMessenger/SnackBar
    一直是哑的（所有提示从未显示）。改自绘底部消息条浮层。
  - **拆图网格整数像素边界**：浮点均分（1024÷3=341.33）把横线画在半
    像素上、抗锯齿糊成灰浅色，而整除方向竖线清晰——即"横线竖线颜色
    不一样"。改 floor 均分 + 末行列吃余数（与 splitGrid 同约定），
    屏上所见==导出裁切。
  - **幽灵选区/参考线清理**：进拆图/拼图工作台未清 widget.selectionRect
    与上一轮吸附 guides，叠在网格上像"某条框线变色"。入口显式重置。
  - **选中框 z-order**：普通框先画、选中框最后画，蓝边不被邻框白边盖半。
- 一期遗留候选：留白背景色可选。

### 九宫格 / 四宫格拆分大图
- **均分版已完成**（2026-11-03，同上分支）：「更多功能」面板（行列
  步进器 + 2×2/3×3 预设 + 边距 0-64px）→ world 全分辨率重合成（标注
  烙进每块）→ `splitGrid` 均分 → N 张 `Screenshot-split-<ts>-<i>.png`
  落 `ScreenshotStore` 目录。
- **已重设计并验收通过（2026-11-06，dev add3735）**：用途明确为
  微信/QQ 朋友圈九宫格——一张图切 N 块、好友时间线拼回原图。故
  面板只留**行/列步进器 + 确定**；确定后进入**拆图工作台**：当前画面
  （含标注）烘成底图，按 rows×cols 均分成**互不重叠、正好铺满**的
  整数像素框架，每格 1:1 显示对应块；框架/取景/吸附/双击预览与拼图
  工作台同一套手势。保存按**文件名+序号**导出 N 张（`mygrid-1.png`…），
  区别于普通单图保存；Ctrl+Z 退出拆图回到拆之前。
- 中途做过又推翻的方案（教训）：实时预览网格 + 间隙色 + 目录选择 +
  预设按钮那套"面板内一站式"被否（太简陋且不符合拼回语义）；正方形
  网格（max(cellW,cellH)）导致非正方图必然溢出重叠、拼不回去。
- 已修：工作台内拆分导出原先直接 return（`_decodedImage` 为 null）。
- 二期候选：按 OCR 文字块行做智能切分（横条带定位）。
