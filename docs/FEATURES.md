# 功能特性清单

> 更新时间：2026-11-03（对应 0.2.0 + 拼图）。历史"待实现"清单全部
> 落地或作废，后续计划见 [ROADMAP.md](ROADMAP.md)。

## 截图与选区

- 区域截图（grim + wlr-screencopy），快捷键在系统 Settings → Shortcuts 绑定
- 整屏截图 ShellAction
- **智能选窗**：框选时悬停高亮窗口，单击整窗成区（QQ/微信式）
- 内存字节直开编辑器（跳过目录轮询）；兼容 deniald 自身截图（目录 watcher）
- 抓帧自动抹光标（借 shell 藏光标信号），置顶卡片输入区只包卡片本身

## 编辑器绘图工具

- 画笔 / 直线 / 箭头 / 矩形 / 椭圆 / 荧光笔（独立粗细）/ 蒙版（模糊或纯色）
  / 文字 / 橡皮（拖动=像素擦除，单击形状=整删）
- 10 标准色 + 主题调色板（明暗阶梯 × 色相 + 最近使用）
- 可自定义快捷键（工具切换/撤销重做/关闭/提示/长截图，settings.json）

## 文字（PPT 式实时编辑，0.2.0）

- 拖框 = 多行文本框（按框宽换行、超出自动缩字号、框内左对齐垂直居中）；
  单击 = 自由单行；双击已有文字就地改
- 所见即所得：草稿与提交渲染共用 `layoutTextBlock`，逐像素一致
- `Enter` 换行 / `Ctrl+Enter` 或点画布提交 / `Esc` 取消（原对象不动）
- 工具栏颜色/字号/字体/**加粗**/**背景色**在编辑中即时写回生效
- 文本背景：半透明/实色预设面板，随工具栏停靠方向 2×6 / 6×2 摆位

## OCR / 翻译

- 本地 PP-OCR v3/v4/v5/v6 + 在线视觉模型 OCR；本地模型目录可选带当场校验
- Argos / M2M-100 离线翻译 + 在线 API 翻译；进度/失败原因可见（超时/401/429）
- 翻译落画布 = 蒙版 + 译文命令（撤销分组一次回退整组）
- **文字多选**（光标模式）：拖拽选字、`Ctrl`+拖拽追加（同行覆盖）、
  ✕ 锚点 `Ctrl`+点释放、`Ctrl+C` 按选取顺序复制

## 长截图

- 滚动拼接：多带 RGB 描述子 + NCC 匹配、吸顶/吸底固定带学习、
  整图重定位兜底、失配丢帧不盲贴
- 自动滚动（注入 Down/Space，wtype/ydotool/桥接三通道）+ 手动滚动
- 探针观测：停稳沿抓帧（无运动糊帧）、到底自动收尾、逐帧抹光标
- 实时预览小窗（可中途结束）、拼接结果直接进编辑器

## 输出

- 保存（文件面板，缺后缀自动补 .png）/ 复制并关闭（状态反馈）/ 置顶悬浮卡
- **拼图一期**：工具栏多选面板（跨目录勾选、按序），等比网格合成新画布
  （不同 DPI/比例自动 contain 对齐），可继续标注
- （拆分导出做过一版，实测后撤回，见 ROADMAP）

## 界面

- 插件全量双语（zh/en，跟随 shell locale）
- 工具栏停靠四边 + 贴边自动隐藏 + 预留模式；选项行/调色板/字体/背景/
  提示面板全部锚定浮层，随停靠方向摆位
- 快捷键提示面板（空格开关，不遮工具栏）

## 已知边界

- 长截图仅纵向（横滚方案实测卡顿，见 ROADMAP 归档）
- 编辑器撤销栈回滚命令不回滚底图（打开/拼图换图 = 清空历史）
